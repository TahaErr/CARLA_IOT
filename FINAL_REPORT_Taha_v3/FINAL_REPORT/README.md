# Final Report — V2X-Sim (V2I + V2V Cooperative Perception)

**Title:** *Mixed Traffic Flow and Edge AI-Supported V2I Communication in
Intelligent Transportation Systems via CARLA Simulation*
**Authors:** Taha Yasin Er, Doruk Topcu — Hacettepe University, Dept. of Computer
Engineering — **CMP 764**

Single-column LaTeX `article` reporting the three-arm (Combined / V2I-only /
V2V-only) cooperative-perception penetration study. Primary results come from the
144-cell Sprint-5 ablation; sensitivity findings from the earlier configuration are
retained as a clearly-labelled section.

## How to compile (Overleaf — recommended)

1. Create a new Overleaf project and upload `report.tex`, `references.bib`, and the
   whole `figures/` folder (keep the folder name `figures`).
2. Set the compiler to **pdfLaTeX** (Menu → Compiler).
3. Compile. Overleaf runs the BibTeX pass automatically; if you compile locally,
   the sequence is:
   ```
   pdflatex report
   bibtex   report
   pdflatex report
   pdflatex report
   ```
The bibliography uses `\bibliographystyle{IEEEtran}` (bundled with Overleaf /
TeX Live). Figure filenames use hyphens (no underscores) so `\includegraphics`
works on every TeX Live version.

## Regenerating the figures (optional)

Requires `python`, `matplotlib`, `pandas`, `numpy`, and the sibling
`SPRINT5_DELIVERABLE/` folder (the data source). From `scripts/`:
```
python make_figures.py     # 10 data charts  -> figures/
python make_diagrams.py    # 3 schematic diagrams -> figures/
python lint_tex.py         # sanity-check report.tex
```
The detector figures (`fig13/14/15`) and the demo-UI screenshots (`figA1/2/3`) are
copied assets, not generated by these scripts.

## Data provenance

All result figures and tables are computed directly from
`SPRINT5_DELIVERABLE/05_combined_eda/all_cells_144.csv` (144 cells, seeds 0+1).
Means are over the 12 cells per (arm, penetration); error bars are ±1 SD
(population), matching `SPRINT5_FINAL_ABLATION.md`. Cross-checked headline values:
total collisions 21.9 / 14.7 / 7.2 / 5.9 (Combined, p = 0.0 / 0.5 / 0.9 / 1.0).
